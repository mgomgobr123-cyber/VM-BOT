Политика конфиденциальности

Как VM Save обрабатывает и защищает ваши данные

📅 Обновлено: 20 сентября 2026

Настоящая Политика конфиденциальности описывает обработку данных Telegram-ботом VM Save (@VMSave_bot). Используя VM Save и подключая его к Telegram Business, пользователь подтверждает, что ознакомился с настоящей Политикой.

1
Назначение сервиса
О боте

VM Save — Telegram Business-бот для уведомления владельца подключённого Business-аккаунта об удалении и изменении сообщений. Для работы этой функции сервис временно обрабатывает данные сообщений через официальный Telegram Bot API и Telegram Business.

2
Какие данные обрабатываются
Сбор информации

VM Save может обрабатывать:

1
Telegram ID пользователя
2
Имя и фамилию
3
Username
4
Информацию о подключении Telegram Business
5
Настройки сервиса
6
Статус подписки
7
Технические идентификаторы платежей
8
Статистику использования

Для работы функций удалённых и изменённых сообщений могут временно обрабатываться:

1
Telegram ID, имя, username отправителя
2
ID чата и ID сообщения
3
Текст сообщения и подпись к медиа
4
Тип сообщения
5
Telegram file_id и file_unique_id
6
Время получения и изменения
📎
Поддерживаемые типы: текст, фото, видео, GIF, голосовые, видеосообщения, аудио, документы, стикеры.
3
Для чего нужны данные
Использование

Данные используются только для:

✓
Работы функций VM Save
✓
Уведомления об удалённых сообщениях
✓
Сравнения старой и новой версии изменённого сообщения
✓
Повторной отправки доступных медиа
✓
Работы настроек пользователя
✓
Управления подпиской
✓
Защиты от злоупотреблений
✓
Технической статистики
💡
Содержимое Business-сообщений не используется для рекламы, создания профилей, обучения ИИ или иных целей, не связанных с функцией VM Save.
4
Срок хранения
7 дней максимум

Данные сообщений хранятся не более 7 дней. Все временно сохранённые данные старше 7 дней автоматически удаляются из базы данных.

⚠️
VM Save не предназначен для постоянного архивирования переписки.
5
Медиафайлы
Обработка вложений

По возможности VM Save не скачивает медиа на собственный сервер. Вместо этого может сохраняться технический идентификатор Telegram — file_id, позволяющий повторно отправить файл через инфраструктуру Telegram.

6
Удаление данных
Ваши права

Пользователь может запросить удаление своих данных. После запроса сервис удаляет данные, которые больше не требуются хранить в соответствии с законодательством.
