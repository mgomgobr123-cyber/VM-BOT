Пользовательское соглашение

Правила использования Telegram-бота VM Save

📅 Обновлено: 20 сентября 2026

Настоящее Пользовательское соглашение регулирует использование Telegram-бота VM Save (@VMSave_bot). Используя сервис, пользователь подтверждает своё согласие с настоящими условиями и Политикой конфиденциальности.

1
О сервисе
Что делает бот

VM Save предоставляет функции для Telegram Business:

→
Уведомление об удалённых сообщениях
→
Уведомление об изменённых сообщениях
→
Отображение предыдущей версии сообщения
→
Повторная отправка доступных медиа
→
Управление настройками уведомлений
→
Платная подписка Premium
2
Подключение
Telegram Business

Для работы основных функций пользователь самостоятельно подключает VM Save через раздел Telegram Business. Пользователь сам выбирает доступные боту чаты, исключения и разрешения. VM Save получает только тот доступ, который предоставлен через Telegram.

3
Временное сохранение
До 7 дней

Для обнаружения удаления или изменения VM Save должен получить сообщение до того, как оно было удалено или изменено. Поэтому сервис временно сохраняет необходимые данные сообщений. Максимальный срок хранения — 7 дней.

⚠️
VM Save не является постоянным архивом переписки.
4
Удаление данных
Ваши права

Пользователь имеет право запросить удаление связанных с ним данных через соответствующую функцию VM Save либо через поддержку. После запроса данные удаляются, кроме случаев, когда сохранение отдельных записей необходимо для выполнения требований законодательства, подтверждения оплаты или разрешения спора.

5
Ограничения восстановления
Когда не сработает

VM Save не гарантирует восстановление каждого сообщения. Сообщение может быть недоступно, если:

!
Отправлено до подключения VM Save
!
Бот не имел доступа к чату
!
Сообщение старше срока хранения
!
Telegram не передал событие
!
Telegram file_id больше недоступен
!
Возникли технические ограничения Telegram
6
Подписка
Premium

Основные функции VM Save могут предоставляться по платной подписке. Тарифы и стоимость отображаются в боте до оплаты. После успешной оплаты подписка активируется на выбранный срок. Если у пользователя уже есть активная подписка, новый срок может быть добавлен к текущему.

7
Оплата
Telegram Stars

Оплата цифровых функций VM Save внутри Telegram производится через Telegram Stars (XTR). Подписка считается оплаченной только после официального подтверждения успешной операции через Telegram.

💡
Сохраняется технический идентификатор платежа для предотвращения повторного начисления и рассмотрения спорных операций.
8
Использование сервиса
Обязательства

Пользователь обязуется:

✓
Соблюдать правила Telegram
✓
Соблюдать применимое законодательство
✓
Не использовать VM Save для угроз, шантажа, преследования
✓
Не пытаться получить несанкционированный доступ
✓
Не использовать уязвимости
✓
Не создавать искусственную нагрузку
✓
Не вмешиваться в работу VM Save
9
Ответственность пользователя
Ваша зона

Пользователь самостоятельно определяет, для каких Telegram Business-чатов он предоставляет доступ VM Save. Пользователь самостоятельно несёт ответственность за соблюдение прав третьих лиц и применимого законодательства при использовании сервиса.
